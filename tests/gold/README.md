# tests/gold

Gold fixtures and expected outputs.

Contains the generated synthetic fixtures (`synthetic-av.mp4`, `synthetic-speech.mp4`) and
their checksums. Regenerate with:

    infra/scripts/mp2.sh fixture
    infra/scripts/mp2.sh speech-fixture

**No third-party copyrighted media belongs here.** Fixtures are fully synthetic and
generated locally. The 50-work gold corpus is out of scope for M0-M4 and must never be
ingested automatically.
