# packages/ontology

MP2's proprietary ontology: the dimensions, vocabularies and controlled terms that evidence
is eventually mapped into.

**Empty by design at M0-M4.** Populating this is calibration work. Inventing dimension
definitions before calibration would bake unvalidated psychometric assumptions into the
canonical layer, which principle 4 (measure before interpreting) exists to prevent.

Like `packages/domain` and `packages/schemas`, this package must never import a provider SDK.
